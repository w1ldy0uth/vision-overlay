# Vision Overlay

Локальное Windows-приложение для отслеживания инвентаря и прогресса Genshin Impact.
Первая бета — **portable-приложение с веб-интерфейсом**. Игровой оверлей ещё в разработке.

## Возможности

- Автоматический захват при запуске игры, ручной запуск и штатная остановка.
- Инвентарь, персонажи, экипировка, таланты, созвездия, отряды, профиль и достижения.
- Live-обновления и автоматическое переключение аккаунта/сервера.
- Импорт доступной истории молитв, live-результаты, pity и событийные гарантии.
- Планировщик улучшений, распределение материалов и гарантированный крафт.
- SQLite, резервные копии, управление хранением, обновляемый справочник и диагностика.

## Скачать и запустить

Скачайте ZIP из [Releases](https://github.com/w1ldy0uth/vision-overlay/releases),
распакуйте **всю папку** в доступное для записи место, например
`%USERPROFILE%/Apps/VisionOverlay`, и запустите `VisionOverlay.exe` обычным пользователем.
Не размещайте portable в Program Files или системных каталогах.

Браузер откроется автоматически; приложение останется в трее. Через меню значка
выберите «Настроить / включить автозахват», укажите `GenshinImpact.exe` и подтвердите UAC.
Затем полностью закройте и запустите игру. Дождитесь первого снимка и синхронизации.

Rust, Node.js и системный Python пользователю не нужны. Общий gi.json включён
с закреплённым источником и SHA256. Профили, БД и токены аккаунта в ZIP не входят.

Живой захват выбирает backend по доступным функциям системной PktMonApi.dll:
новый PacketMonitor realtime API либо совместимый PktMon/ETW для Windows 10.
Для ETW требуется свободный PktMon и пустой список глобальных фильтров; чужие
сессии и фильтры приложение не останавливает и не очищает. Поддержка Windows 10
пока экспериментальная и требует живой проверки на машине тестера.
Живые проверки основного backend проводились на Windows 11 и глобальном клиенте GenshinImpact.exe. Нужны Windows PowerShell 5.1, браузер и права администратора
для фонового захвата. Сервер и интерфейс работают без повышения прав.

**Ограничения беты:** проверка на чистой Windows отложена, EXE и PowerShell-скрипты
не подписаны. Поддерживается проверенная сборка игры; после обновления игры может
потребоваться совместимая версия декодера. Установщика и in-game overlay пока нет.

## Разработка

Нужны Windows x64, Git, Rust/MSVC 1.99.1 с C++ Build Tools и Node.js 24.
Для тестов нужен Python 3.14 с зависимостями из requirements-dev.txt.

```powershell
git clone https://github.com/w1ldy0uth/vision-overlay.git
cd vision-overlay
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File ./scripts/Build-Portable.ps1
```

Полный начальный справочник включён как проверяемый сжатый пакет в packaging/catalog.
Сборка не читает БД, профили, ключи или кеши из другой установки. Результат — в dist;
рядом с ZIP создаётся SHA256. Версия определяется workspace.package.version
в Cargo.toml, коммит сборки записывается в манифест и диагностику.
