# Изменения

## 0.1.2-beta.1 — 2026-11-18

- Добавлена обработка кадров IEEE 802.11 в обоих путях захвата и счётчики форматов кадров. Снимок и live-обновления проверены по Wi-Fi на Windows 11. Проверка PktMon/ETW на Windows 10 остаётся открытой.
- Доставка повторяет временный конфликт привязки профиля и сохраняет журнал при несовпадении контрольной суммы обработанных событий. Возобновление доставки после перезапуска той же сборки проверено при открытой игре.

## 0.1.1-beta.1 — 2026-11-16

- Экспериментальный PktMon/ETW backend для Windows 10; автоматический выбор по доступным функциям API.
- Предварительная проверка окружения, явный выбор backend для диагностики и понятные ошибки совместимости.
- Ограниченные очереди и буферы ETW, учёт потерь, фильтрация игрового UDP до raw-записи и штатное освобождение захвата.
- ETW не останавливает чужой PktMon и не очищает глобальные фильтры; при занятом PktMon или неизвестных/непустых фильтрах запуск отклоняется.
- Импорт молитв использует сохранённый путь к игре с резервным поиском через лог; сетевая недоступность API диагностируется отдельно, без вывода авторизации.
- Новые тесты выбора backend, очередей, фильтрации и CI-проверки; тестовые данные исключены из публикации.

ETW проверен принудительно на Windows 11 с тестовым UDP и сохранённым ETL.
Живой прогон игры на Windows 10 ещё не подтверждён. EXE/PowerShell не подписаны.

## 0.1.0-beta.1 — 2026-11-16

Первый публичный prerelease Windows x64 с локальным веб-интерфейсом.

- Автозахват, ручное управление, live-инвентарь, несколько профилей и серверов.
- Персонажи, экипировка, постоянные характеристики, таланты/созвездия и стихии Путешественника.
- Профиль, отряды, достижения, история молитв, pity и событийные гарантии.
- Планировщик, распределение материалов и гарантированный крафт.
- SQLite, резервные копии, управление хранением и диагностический ZIP.
- Portable launcher, полный справочник, свой Python и общий gi.json; настройка только пути игры.
- Сборка из чистого клона, CI, публичные инструкции, атрибуция и лицензии.

Чистая Windows пока не проверена. EXE/PowerShell не подписаны. Игровой оверлей
и установщик ещё не входят. После патчей игры может требоваться обновление декодера.
