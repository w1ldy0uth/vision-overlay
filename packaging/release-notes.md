Vision Overlay v0.1.2-beta.1 — portable для Windows x64.

- Захват обрабатывает кадры IEEE 802.11 и сообщает их количество в диагностике. На Windows 11 по Wi-Fi подтверждены стартовый снимок и live-обновления.
- При временном конфликте привязки профиля доставка повторяет запрос. При расхождении контрольной суммы обработанных событий журнал сохраняется для диагностики. Проверен перезапуск той же сборки сервера при открытой игре.

Поддержка Windows 10 через PktMon/ETW экспериментальная. Живой тест обновлённого захвата по Wi-Fi на Windows 10 ещё впереди.

Распакуйте архив в доступную для записи папку и запустите VisionOverlay.exe. При обновлении следуйте инструкции по переносу данных и настройке наблюдателя. [Инструкция](https://github.com/w1ldy0uth/vision-overlay/blob/main/guides/MAINTENANCE.md).
