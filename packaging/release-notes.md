Первая публичная бета Vision Overlay для Windows x64: локальный веб-интерфейс,
автозахват и live-обновления инвентаря, персонажей и других данных аккаунта.

Включены профиль, отряды, достижения, история молитв с pity/гарантиями,
планировщик, распределение материалов, копии и диагностика.

**Запуск:** распакуйте ZIP в доступную для записи папку пользователя,
например `%USERPROFILE%/Apps/VisionOverlay`, и запустите VisionOverlay.exe.
Не используйте Program Files. Через меню трея выберите настройку захвата,
укажите GenshinImpact.exe и подтвердите UAC. Затем полностью перезапустите игру.
Общий gi.json включён; Rust, Node.js и системный Python пользователю не нужны.

**Ограничения:** проверка чистой Windows отложена; EXE/PowerShell не подписаны.
Поддерживается проверенная сборка глобальной игры, совместимость контролируется
хешами. In-game overlay и установщик ещё не входят. Автозапуск привязан к пути;
перед переносом/обновлением следуйте инструкции в репозитории.

Живые сценарии проверены пользователем. CI проверяет код, сборку и portable без
реальной игры; это не заменяет отложенную проверку чистой Windows.

Приложены ZIP, SHA256 и отчёт проверки. Публичные инструкции и лицензии — в
репозитории. Перед баг-репортом проверяйте диагностические вложения на секреты.
