Vision Overlay v0.1.1-beta.1 — полный portable-комплект Windows x64.

Изменения относительно v0.1.0-beta.1:

- Экспериментальный PktMon/ETW backend для Windows 10. При наличии нового API продолжает использоваться PacketMonitor realtime; backend выбирается автоматически.
- Проверка системного API перед захватом и диагностический Test-CaptureEnvironment.ps1.
- Ограниченные очереди/буферы, учёт потерь ETW и фильтрация игрового UDP до записи raw. Чужие сессии и глобальные фильтры PktMon остаются нетронутыми; занятый PktMon и неизвестный/непустой список фильтров отклоняют запуск ETW.
- Улучшен поиск папки игры при импорте молитв и диагностика сетевой недоступности API. Ссылки и authkey в логи не выводятся; настройки маршрутов/VPN приложение не меняет.

**Статус Windows 10:** экспериментальная поддержка. На Windows 11 принудительно проверены запуск ETW, доставка тестового UDP, нулевые потери и остановка; на сохранённом ETL проверен разбор 11 501 пакета. Живой прогон игры на Windows 10 у тестера ещё требуется. Это не заявление о завершённой проверке чистой Windows 10/11.

**Обновление:** полностью закройте игру, завершите старый наблюдатель и сервер, создайте резервную копию. Распакуйте новую версию отдельно, перенесите data и заново настройте автозахват для нового пути. Не смешивайте components разных полных релизов. [Полная инструкция обновления](https://github.com/w1ldy0uth/vision-overlay/blob/main/guides/MAINTENANCE.md).

**Первый запуск:** распакуйте ZIP в доступную для записи папку пользователя (не Program Files), запустите VisionOverlay.exe. В меню трея выберите настройку захвата, укажите GenshinImpact.exe, подтвердите UAC и полностью перезапустите игру. Общий gi.json, Python и справочники включены; Rust, Node.js и системный Python пользователю не нужны.

Включены профиль, отряды, инвентарь, персонажи/экипировка, достижения, молитвы с pity/гарантиями, планировщик, резервные копии и диагностический экспорт.

**Ограничения:** EXE/PowerShell не подписаны. Нужна совместимая проверенная сборка глобальной игры. In-game overlay и установщик ещё не входят. ETW на Windows 10 требует свободного глобального PktMon и пустого списка фильтров.

Приложены полный ZIP, SHA256 и отчёт portable-проверки CI. Публичные инструкции и лицензии находятся в репозитории и комплекте. Перед отправкой баг-репорта проверяйте диагностические вложения на секреты.
