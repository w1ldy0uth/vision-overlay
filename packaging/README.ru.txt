Vision Overlay — переносимая тестовая версия для Windows x64

1. Распакуйте всю папку из ZIP в доступное для записи место. Не запускайте
   приложение внутри архива. Не используйте Program Files и системные каталоги.
2. Запустите VisionOverlay.exe. Откроется браузер, приложение останется в трее.
   Двойной клик по значку открывает интерфейс, правая кнопка — меню.
3. Для захвата выберите «Настроить / включить автозахват» и укажите
   GenshinImpact.exe. При настройке Windows
   запросит права администратора. Сам интерфейс работает без повышения прав.
4. После настройки полностью закройте игру и запустите её снова. Дождитесь
   снимка и статуса синхронизации в приложении.

Общий файл dispatch-ключей gi.json уже входит в комплект беты. При первом
запуске он автоматически размещается в data; вручную искать его не нужно.
Источник: konkers/irminsul, keys/gi.json, ревизия
49e66bdfc43c4c6e4293e7f1b7e85b6988069ae4.
Это общие данные декодера, а не персональные ключи игрового аккаунта.
Происхождение и SHA256: components/reference/dispatch-source.json.
Лицензия исходного проекта: licenses/Irminsul-LICENSE.txt.

Поддерживается только проверенная сборка игрового клиента. Настройка сверяет
файлы игры по SHA256; другая версия потребует обновления Vision Overlay.
Файлы игры не копируются в комплект и не изменяются.

Rust, Node.js и системный Python для запуска не нужны. Python для синхронизации
истории молитв находится внутри components/python. Нужны Windows x64,
Windows PowerShell 5.1, обычный браузер и установленная игра.

Данные создаются в data рядом с EXE. Публичный ZIP не содержит чужих профилей,
истории, БД, токенов аккаунта или журналов. Резервные копии создаются/восстанавливаются
через интерфейс приложения. Для переноса существующих профилей используйте
резервную копию; не копируйте SQLite-файл во время работы приложения.

Порт переносимой версии: 18789. Разработка обычно использует 18788.
Если порт занят, приложение покажет ошибку. При необходимости создайте
data/launcher.json с содержимым {"port":18790} перед запуском.

Захват — отдельный фоновый компонент. Закрытие вкладки браузера его не завершает.
«Закрыть интерфейс и сервер» в трее штатно закрывает сервер; настроенный
наблюдатель продолжает работать, захват завершится после выхода из игры.
Кнопки ручного запуска/остановки доступны в «Настройки → Захваты и снимки».
Не включайте одновременно захват из двух установок Vision Overlay.

Перенос папки: выйдите из игры, отключите автоматический захват, закройте сервер.
Удалите старую задачу VisionOverlay-AutoCapture-* в Планировщике заданий Windows
(имя своей задачи указано в data/auto-capture/configured.json). Перенесите папку
целиком и повторите настройку захвата. Задача привязана к абсолютному пути.
Удаление приложения: после этих же действий удалите папку; данные удалятся с ней.

Обновление: выйдите из игры и закройте сервер, сохраните резервную копию.
Распакуйте новую версию отдельно, перенесите data в новую папку, затем повторите
настройку автозахвата. Не заменяйте работающие EXE и не смешивайте components
из разных версий. Старую папку оставьте до проверки восстановления.

Диагностика: Настройки → Захваты и снимки → Экспорт для баг-репорта.
Raw-пакеты включаются отдельно и могут содержать сессионные сетевые данные.
Ничего автоматически не публикуется и не отправляется.

Первая публичная бета: проверка на чистой Windows отложена. EXE и PowerShell-скрипты
не подписаны. Живые сценарии проверены пользователем; автоматическая проверка
на сборочной машине не заменяет проверку чистого пользовательского окружения.
