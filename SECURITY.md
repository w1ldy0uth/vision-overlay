# Безопасность и диагностика

API слушает loopback. Приём событий требует локальный collector token;
управляющие API проверяют Origin и служебный заголовок. Захват вынесен в отдельный
повышенный компонент. Интерфейс не должен запускаться администратором.

Не публикуйте токены, authkey и ссылки авторизации, папку data, SQLite или backup
целиком, а также непроверенные raw/диагностические архивы. Экспорт маскирует известные
секреты в текстах, но сохраняет UID/игровые данные. Raw не обезличивается.
Автоматической отправки нет.

Если проблема затрагивает секреты или повышение прав, начните с краткого сообщения
сопровождающему через [профиль GitHub](https://github.com/w1ldy0uth), без секретных данных.
До согласования канала не передавайте рабочие учётные данные и персональный capture.

Общие файлы из packaging/public-crypto-material.json — публичные upstream-материалы,
проверенные по точным SHA256. Это не разрешение публиковать другие ключи.
