# Данные, обновление и удаление

БД, настройки, профили, справочники, кеш, журналы и захваты находятся в data рядом
с EXE. Папка должна быть доступна для записи обычному пользователю.

## Резервная копия

Используйте «Настройки → Резервные копии»: ручное создание позволяет выбрать путь,
восстановление проверяет формат .visionbackup. Не копируйте работающий SQLite-файл
отдельно от WAL. Диагностический ZIP не предназначен для восстановления.

## Обновление или перенос

1. Полностью выйдите из игры и дождитесь окончания захвата.
2. Отключите автоматический захват через меню трея.
3. Найдите имя своей задачи в data/auto-capture/configured.json. В Планировщике
   заданий Windows остановите и удалите **именно эту** задачу VisionOverlay-AutoCapture-*.
   Отключение автоматических стартов само по себе оставляет помощник для ручных команд.
4. Создайте резервную копию и закройте сервер через меню трея.
5. Распакуйте новую версию отдельно и перенесите data целиком. Не смешивайте
   components разных версий и не заменяйте работающие EXE.
6. Запустите новую копию и повторите настройку: задача привязана к абсолютному пути.
7. Проверьте профиль и live-событие; старую папку оставьте до завершения проверки.

Для удаления выполните шаги 1–4, затем удалите папку приложения. Данные удаляются
с ней; ручные копии вне папки остаются на выбранном вами месте.

## Хранение и совместимость

Сохраняются три точки восстановления на профиль; raw ограничен кольцевым бюджетом.
Вытесненные raw-сегменты восстановить нельзя. Предпросмотр очистки и защищённые
данные доступны в «Настройки → Хранение данных». Ручные копии автоматически не ротируются.

Новая схема БД отвергается старой версией приложения. Используйте штатное
восстановление копии. После патча игры может требоваться совместимый релиз декодера.
