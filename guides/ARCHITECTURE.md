# Архитектура и ограничения

VisionOverlay.exe запускает сервер и открывает веб-клиент. app-server содержит
HTML/CSS/JS, loopback API/SSE, каталог, резервные копии и диагностику. app-store
реализует SQLite, последовательное применение событий и расчёты.

capture-probe работает отдельно с повышенными правами, используя Windows pktmon
и модифицированный auto-artifactarium. Наблюдатель отслеживает GenshinImpact.exe
и запускает/останавливает захват. Собственный драйвер не устанавливается.
Интерфейс и сервер запускаются без повышения прав.

События сохраняются в журнал, затем принимаются в БД. При перезапуске сервера
захват продолжает запись, доставка возобновляется после запуска. Снимки задают
подтверждённое состояние, live-события обновляют его; разрывы обозначаются явно.
Профили разделены по UID и серверу. Общие dispatch/PEM-файлы декодера — публичные
upstream-данные, а сессионные данные и авторизация аккаунта остаются локальными.

## Ограничения беты

- Windows x64, глобальный GenshinImpact.exe; другие ОС/клиенты не проверены.
- Отдельный формат стартового пакета поддерживает только хеш-проверенную сборку игры.
- Для полного состояния нужен стартовый снимок; один подбор его не заменяет.
- Временные боевые эффекты не учитываются в постоянных характеристиках.
- История молитв зависит от доступной API-истории и действующего доступа в кеше.
- Реконструкция сабстатов не прошла отдельную живую проверку.
- ККИ, гайды/сборки, другие ОС, полноценный игровой оверлей и установщик не входят.
- Проверка на чистой Windows отложена; бинарники и PowerShell-скрипты не подписаны.
- Перенос/удаление требуют явного удаления старой задачи Windows по инструкции.
